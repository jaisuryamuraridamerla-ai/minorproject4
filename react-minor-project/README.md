# Week 04 Minor Project – To-Do App + Notes App (React)

Two small React applications built with Vite for the Unlox Web Development Week 04 minor project.

| App | Folder | What it does |
|-----|--------|--------------|
| Taskly | [`todo-app`](./todo-app) | Task manager with filtering, due dates and Local Storage |
| Jotter | [`notes-app`](./notes-app) | Note-taking with search, categories, timestamps and Local Storage |

## Setup (for either app)

Requires Node.js 18+.

```bash
cd todo-app        # or: cd notes-app
npm install
npm run dev        # open the URL shown in the terminal
```

Production build: `npm run build`

## Technologies Used

- React 18 (functional components, hooks)
- Vite 5
- JavaScript (ES6+)
- CSS3 (Grid, Flexbox, media queries)
- Browser Local Storage

## React concepts demonstrated

Functional components, JSX, props, `useState`, `useEffect`, event handling, conditional rendering, list rendering with `.map()`, reusable components.

## JavaScript concepts demonstrated

Arrow functions, template literals, destructuring, spread operator, `let`/`const`, `map()`, `filter()`, `find()`, object manipulation.
